# 发行元数据

简体中文 · [English](README.md) · [项目主页](../README.zh-CN.md) · [文档](../docs/README.zh-CN.md)

本目录保存机器可读的发行记录，不存放安装包二进制。

- [manifest.json](manifest.json)：5 个公开发行组的准确文件名、字节数、SHA-256、原始发布时间与下载 URL。
- [tag-map.json](tag-map.json)：6 个保留标签及其准确提交指向。
- [根目录 SHA256SUMS](../SHA256SUMS)：供命令行验证的安装包校验值。

下载与说明见[发行索引](../docs/releases/README.zh-CN.md)，产品二进制附件位于 GitHub Releases。`main` 可以继续演进，已发布标签保留其历史快照。
