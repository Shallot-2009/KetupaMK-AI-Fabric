# 仓库检查

简体中文 · [English](README.md) · [项目主页](../README.zh-CN.md) · [文档](../docs/README.zh-CN.md)

在包含完整原始历史和标签的 Git 副本根目录执行：

```bash
python3 tools/check_repository.py
```

脚本仅使用 Python 标准库，核对完整的 111 文件基础项目、17 个发行保全记录、两个公开授权、安装包/标签元数据、第三方哈希、语言配对、链接/锚点及已知凭据特征。它不执行归档代码、安装器、授权操作或 EDA 工作流。

GitHub Actions 执行相同命令。浅克隆需先取得原始历史和标签。已发布文件基准的变更需要明确审核，不应只修改清单就重新定义基础项目的保全依据。
