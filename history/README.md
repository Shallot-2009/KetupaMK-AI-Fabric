## Origin and role

**Ketupa_v0.0.3 is the original foundational project from which KetupaMK evolved.** Its complete project tree is retained at [Ketupa_v0.0.3/](Ketupa_v0.0.3/). The archive is a historical baseline, with original code, documents, assets, simulation projects, models, inputs, results, author credits, and legal statements kept together.

The baseline is commit `b5f44c111fef3d32b5cdeb3c18d4af40e5c81306` in the original `Shallot-2009/Ketupa_v0.0.3` repository. All **111 tracked files** retain their names, relative paths, bytes, and Git file modes. Archive tree: `ea29d263d3a6c98b62ef9cb17c326523e5cc383b`, identical to the original project root.

- [Original README](Ketupa_v0.0.3/README.md)

- [Origin and timeline](ORIGIN.md)

## Obtain the complete project

```bash
git clone https://github.com/Shallot-2009/KetupaMK-AI-Fabric.git
cd KetupaMK-AI-Fabric/history/Ketupa_v0.0.3
```

The `legacy-v0.0.3` tag preserves the original root layout. To work in that layout without changing your main checkout:

```bash
git clone --branch legacy-v0.0.3 https://github.com/Shallot-2009/KetupaMK-AI-Fabric.git Ketupa_v0.0.3
```

Both original repositories' Git histories remain reachable from `main`. The archive directory was renamed from `0.0.3/` to `Ketupa_v0.0.3/` on 2026-11-18 to retain the original project name.

## Preservation rules

Treat the directory as a frozen historical record. Place explanations, corrections, and navigation outside `Ketupa_v0.0.3/`. Repository checks compare its tree and all file hashes with the original baseline. Do not overwrite it with current product files, change its original authorship, or relicense it under current proprietary terms.

The project began in **2023**, with early project commits in **May–June 2024** confirmed by the maintainer. The earliest Git commit currently retained in this migrated repository is **2025-06-20**, and the original README records the v0.0.3 release on **2025-08-14**. These dates describe different events; see the [history and evidence record](ORIGIN.md). Historical claims and plans are retained as records, not current-product acceptance statements.

## Historical environment

Original clone URLs, `./Ketupa/` paths, package names, and script spellings may be obsolete. The dependency file says `pytorch==2.2.2`, and the README references `Auto_desk.py` while the actual file is `Auto_desktop.py`. These original records remain unchanged. Windows COM, HFSS, SI9000, MATLAB, and engineering-file rights require compatible environments and separate permissions.

Original first-party source retains its archived license; earlier BSD-2-Clause grants remain effective. Third-party artifacts retain their own rights. Use the [current product downloads](../README.md#downloads-en) for present distributions.
