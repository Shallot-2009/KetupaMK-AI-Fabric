There are five public release groups with fifteen installer assets. Runtime 1.0.0 and product 1.0.0 are separate distributions. Names and installer bytes are preserved. Download an installer for your platform, then follow the [installation guide](../installation/README.md) and verify [SHA256SUMS](../../SHA256SUMS).

| Reference | Meaning |
| --- | --- |
| `main` | Current documentation, download links, and preservation records |
| `openketupamk-v*` | Product release snapshots |
| `openketupamk-runtime-v*` | Runtime snapshots |
| `openketupamk-beta` | Preserved historical Beta snapshot |
| `legacy-v0.0.3` | Foundational project in its original root layout |

The [tag map](../../releases/tag-map.json) records exact commits. Several historical distribution tags share a documentation commit; their separate installer assets remain distinct. Existing tags keep their original targets, even when the current `main` layout differs. [Publishing policy](../governance/README.md).

GitHub-generated Source code archives contain the tagged repository snapshot, not protected product installers. Original publication times are retained in the [release manifest](../../releases/manifest.json); GitHub's migrated-release timestamps describe the later migration.
