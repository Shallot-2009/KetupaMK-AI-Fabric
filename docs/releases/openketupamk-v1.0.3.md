## Installation and licenses

Run the EXE on Windows. On Linux, install the DEB with your package manager or extract the TAR.GZ and run `ketupa-setup`. For an existing installation, use the same package format and installation directory. Follow the [installation guide](../installation/README.md).

Use a signed license with the modules required by your workflow. The two listed 1.0.2 public test files are also accepted within their existing terms. Newly issued 1.0.3 licenses require the applicable 1.0.3 modules. [Test license downloads and activation](../../licenses/README.md)
