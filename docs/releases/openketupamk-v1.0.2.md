## Version scope

This preview publishes CIR-based PKG/PCB/Merge workflow entries, package/interconnect configuration, mixed-unit sweeps, DDR Touchstone delay/skew reports, traceable outputs, AI network-data preparation, optional Skill/Agent/MCP integration, and local authenticated HTTPS interfaces. GDS Interposer assistance is import-only. Windows provides a Launcher; Linux provides the CLI.

The [product guide](../product/README.md) gives the detailed published scope and inputs. A valid 1.0.2 entitlement and compatible, separately licensed EDA tools are required. Fifteen workflow entry points do not establish completed physical acceptance of all scenarios.

本预览版提供 CIR 驱动的 PKG/PCB/Merge 入口、封装与互连配置、混合单位扫频、DDR Touchstone 延迟/skew 报告、可追溯输出、AI 网络数据准备、可选 Skill/Agent/MCP 集成，以及带鉴权的本地 HTTPS 接口。GDS Interposer 仅提供导入辅助；Windows 提供 Launcher，Linux 提供 CLI。

具体已发布范围与输入要求见[产品说明](../product/README.md)。执行需要有效的 1.0.2 授权和兼容、另行获准使用的 EDA 工具。15 种入口不代表全部场景已完成真实物理验收。
